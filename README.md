# 🧠 CodeMate AI — Code Explanation Assistant

**CodeMate AI** is an intelligent web application that explains any piece of code in plain, human-understandable language.  
It’s designed for developers, students, and learners who want quick, accurate explanations of complex code — powered by AI.

---

## 🚀 Tech Stack

### 🔹 Frontend
- React (Vite)
- Tailwind CSS
- Hosted on **Netlify**

### 🔹 Backend
- Node.js + Express
- Hosted on **Render**
- Integrated with an AI API for code interpretation

### 🔹 Package Manager
- Yarn
